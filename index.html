3. Bot Telegram Pengingat Otomatis

OTOMATIS 15 MENIT

Mengingatkan pegawai di grup atau chat personal jika sudah lewat jam masuk / pulang yang telah diatur.

key
Dapatkan token ini dari akun Telegram @BotFather saat membuat bot.

Untuk grup kantor gunakan ID diawali -100... (jadikan bot sebagai Admin grup).
info Panduan Praktis Setup Bot Telegram dalam 2 Menit:
  1. Buka aplikasi Telegram, cari @BotFather, lalu kirim perintah /newbot. Ikuti instruksi dan beri nama bot Anda. Salin HTTP API Token ke kolom di atas.
  2. Buat Grup Telegram bersama pegawai atau admin, lalu undang bot Anda ke dalam grup tersebut dan jadikan sebagai Admin.
  3. Untuk mengetahui Chat ID grup: masukkan bot @RawDataBot ke dalam grup, cari baris "id": -100xxxxxxx, lalu salin angka tersebut ke kolom Chat ID di atas (atau chat personal ke bot Anda untuk tahu ID pribadi).
  4. Klik tombol Simpan Pengaturan, lalu klik Test Kirim Pesan untuk memverifikasi.
  5. Klik tombol Pasang Pemicu (Trigger) agar server Google otomatis memeriksa jam kerja dan mengirim pengingat setiap 15 menit.
Pengaturan disimpan langsung ke lembar sheet Pengaturan di Google Spreadsheet.
